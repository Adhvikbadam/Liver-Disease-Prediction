# Liver Disease Prediction

A Machine Learning based web application that predicts the possibility of liver disease using patient clinical data.

## Features

- Predicts liver disease using a trained SVM model
- Takes clinical patient inputs
- Uses preprocessing and feature scaling
- Simple Streamlit web interface

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Support Vector Machine
- Streamlit
- Joblib

## Project Files

- `app.py` - Streamlit application
- `svm.pkl` - Trained SVM model
- `scaler.pkl` - Feature scaler
- `columns.pkl` - Model feature columns

## How to Run

Install required libraries:

```bash
pip install streamlit pandas numpy scikit-learn joblib
